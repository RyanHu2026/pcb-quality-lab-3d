# UI 设计规范（去 AI 味）

> 这份文档是照 Apple HIG / Material 3 / Vercel Web Interface Guidelines 的公开原则蒸馏出来的，
> 目的是让界面看起来像「有人认真做过设计的产品」，而不是「模型生成的深色渐变控制台」。
>
> 参考来源：
> - [vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines)（交互 / 无障碍 / 排版细则）
> - [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)（层级、留白、克制用色）
> - [Material Design 3](https://m3.material.io/)（color roles、type scale、state layer）
> - [Radix Colors](https://www.radix-ui.com/colors)（成体系的灰阶与语义色）
> - [shadcn/ui](https://ui.shadcn.com/)（中性色 + 1px 描边的实际手感）

## 一、先认识「AI 味」长什么样

以下 12 条是模型生成界面最典型的痕迹，逐条对照删掉：

| # | AI 味 | 替代做法 |
| --- | --- | --- |
| 1 | 深蓝底 + 青色发光（`#47d7e8` + `box-shadow: 0 0 40px`） | 纯中性深色 `#0a0a0b`，光靠层级不靠发光 |
| 2 | 卡片用 `linear-gradient(180deg, #131b24, #0f161d)` | 单一纯色 `#141416` |
| 3 | 彩色 1px 描边（青色边框） | `rgba(255,255,255,.08)` 中性描边 |
| 4 | 每个标题上面一行全大写英文小字（`STACK-UP EXPLORER`） | 能删就删；必须留就 11px、字距 0.02em、灰 |
| 5 | 所有卡片一个模子：图标 + 标题 + 两行描述 + 箭头 | 至少让主卡片（hero）在尺寸和排版上明显不同 |
| 6 | 渐变按钮 + hover 发光 | 实色按钮，hover 只变背景 |
| 7 | 圆角 18–24px 到处飞 | 卡片 12、按钮 9、内层更小 |
| 8 | 等宽字体滥用（数字、英文全用 mono） | 只有真正对齐的数字用 `tabular-nums` |
| 9 | 每个区块都套一个卡片，页面被切成碎片 | 用留白和分隔线分组，少用卡片 |
| 10 | 图标全都带彩色底块 + 圆角发光 | 线性图标 1.5px，单色 |
| 11 | 动效 300ms 弹跳、`transition: all` | 150–200ms `ease-out`，只动 `opacity/transform` |
| 12 | 一屏放 5 个功能卡片，信息密度均匀 | 建立层级：一个主视觉 + 次级内容 + 稀疏列表 |

## 二、色彩

**规则：一个强调色，其余全是中性灰。**

```css
:root {
  /* 中性色阶：从背景到文字，只调明度，不调色相 */
  --bg:      #0a0a0b;   /* 页面底 */
  --panel:   #141416;   /* 卡片 */
  --panel-2: #101012;   /* 次级卡片 / 输入框 */
  --line:    rgba(255,255,255,.08);  /* 分隔线 */
  --line-2:  rgba(255,255,255,.18);  /* 需要更明显的边界时 */
  --text:    #f5f5f7;
  --dim:     #a1a1a6;
  --dim-2:   #6e6e73;

  /* 强调色只用一个（Apple 蓝 / Google 蓝） */
  --accent:  #0a84ff;
  --accent-hover: #0077ed;

  /* 语义色只在「状态」里出现，不当装饰 */
  --red:   #ff453a;
  --green: #30d158;
  --amber: #ffd60a;
}
```

- 浅色主题就把 `--bg` 换成 `#fff`、`--panel` 换成 `#f5f5f7`、`--line` 换成 `rgba(0,0,0,.08)`，其余不动。
- 语义色（红/绿/黄）只用于「对/错/警告」，不用于强调、不用作图标底色。
- 需要「更高一层」时：先加背景明度差，再加 1px 描边，最后才考虑阴影。**阴影不是层级的第一手段。**

## 三、排版

**字号阶梯（只从这里选，不要临时拍脑袋）：**

| 用途 | 字号 | 行高 | 字重 |
| --- | --- | --- | --- |
| 页面大标题 | 28–32 | 1.25 | 600 |
| 区块标题 | 18–20 | 1.4 | 600 |
| 卡片标题 | 14–15 | 1.45 | 600 |
| 正文 | 13–15 | 1.65–1.8 | 400 |
| 辅助说明 | 12 | 1.6 | 400 |
| 标签 / 角标 | 10.5–11 | 1.4 | 500 |

- 字体栈用系统字体：`-apple-system, "SF Pro Text", "PingFang SC", "Microsoft YaHei", system-ui`。
  中文在 13px 以下会发虚，**正文最小 13px，理想 15px**。
- 一行中文控制在 **28–34 字**（约 560px 宽），太长就分栏或收窄。
- 数字用 `font-variant-numeric: tabular-nums`，不要为此把整段换成等宽字体。
- 全大写英文只用于极短的标签（≤ 3 个词），字号 ≤ 11px，字距 0.02–0.06em。

## 四、间距与圆角

- 间距只用 **4 的倍数**：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 卡片内边距：16（紧凑）或 20–24（宽松）。同一屏内不要混用三种以上。
- 区块之间 24–40，比卡片内边距大，页面才有呼吸感。
- 圆角：卡片 12、按钮 9、标签 6、小方块 4。
- **嵌套圆角要同心**：子元素圆角 ≤ 父圆角 − padding。

## 五、描边与阴影

```css
/* 描边：半透明中性色，比实色更耐看 */
border: 1px solid rgba(255,255,255,.08);

/* 阴影：两层，模拟环境光 + 直射光；不要彩色、不要发光 */
box-shadow:
  0 1px 2px rgba(0,0,0,.60),
  0 12px 32px rgba(0,0,0,.24);
```

- 卡片默认**不加阴影**，用背景差 + 描边区分层级；只有浮层（弹窗、下拉、抽屉）才加阴影。
- hover 时增加对比（背景亮一点 / 描边亮一点），而不是加阴影。

## 六、交互与动效

- 所有可点元素必须有 `:focus-visible` 焦点环：`outline: 2px solid var(--accent); outline-offset: 2px`。
- 移动端点击区域 ≥ 44×44px（视觉可以小，热区不能小）。
- 动效 150–200ms，`cubic-bezier(.2,0,0,1)` 或 `ease-out`；只动 `opacity` 和 `transform`。
- **禁止 `transition: all`**，只写你要动的那几个属性。
- 尊重 `prefers-reduced-motion`。
- 按钮的四种状态都要画：rest / hover / active / disabled + 加载态。

## 七、页面结构（比配色更影响「像不像人做的」）

1. **一个有主次的版式**：一屏里只有一件事是主角（大标题或一个大图），其余退后。
2. **不要每块内容都装进卡片**：连续文本、列表、说明直接排在页面上，用分隔线或留白分段。
3. **密度要有变化**：主视觉宽松（padding 32+），次要信息收紧（16），不要全页一个密度。
4. **图标克制**：一个区块最多一个图标；能用排版解决的不用图标。
5. **空状态、加载态、错误态**都要设计，不要只画「有数据」的样子。

## 八、自检清单（提交前逐条过）

- [ ] 全站只有 1 个强调色；红/绿/黄只出现在状态里
- [ ] 没有任何 `linear-gradient` / `radial-gradient` 用作背景
- [ ] 没有任何 `box-shadow` 带颜色或模糊半径 > 40 的发光
- [ ] 所有描边都是半透明中性色
- [ ] 字号只取自第二节的阶梯；中文正文 ≥ 13px
- [ ] 间距是 4 的倍数；同屏内边距不超过 3 种
- [ ] 圆角 ≤ 16，且嵌套同心
- [ ] 没有 `transition: all`
- [ ] 键盘 Tab 一圈，焦点环都看得见
- [ ] 移动端 390px 宽下没有横向滚动、按钮热区 ≥ 44px

## 九、给 AI Agent 的硬约束

写 UI 代码时，除非用户明确要求，**不要**：

1. 加发光、霓虹、彩色阴影；
2. 用渐变做背景或按钮；
3. 一个页面塞超过 2 个强调色；
4. 给每个区块都套卡片；
5. 用全大写英文当装饰性小标题；
6. 用 `transition: all`；
7. 把圆角堆到 16 以上；
8. 用 emoji 代替图标。

**要**：
1. 先定 tokens（颜色/字号/间距/圆角），再写组件；
2. 用系统字体；
3. 用背景差 + 1px 描边做层级；
4. 让一个元素明显是主角；
5. 交付前跑一遍第八节的清单。
